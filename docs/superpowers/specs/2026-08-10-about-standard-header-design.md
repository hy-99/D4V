# About Standard Header

## Goal

Make the About page use the same light header treatment as standard inner pages and make the shared “Bay Area” wordmark upright rather than italic.

## Changes

- Remove the About-only Home navigation item, smaller link sizing, blue active underline, blue Get Help pill, and blue mobile-menu accent.
- Keep About's light header tone because its hero background is light.
- Preserve logo size, crop, position, navigation routes, mobile behavior, and accessibility.
- Keep “Bay Area” in the existing editorial serif but remove italic styling across the shared header.
- Do not change the homepage layout, About content sections, or footer.

## Validation

- Compare About and a standard light inner-page header for navigation labels, link sizing, Get Help styling, and spacing.
- Confirm “Bay Area” computes to `font-style: normal` on desktop and mobile.
- Re-run header keyboard, mobile menu, responsive, and production checks.
