# D4V illustration assets

These SVG scenes are downloaded locally from the unDraw SVG collection mirror:
https://github.com/balazser/undraw-svg-collection

The artwork originates from unDraw. See the current license at:
https://undraw.co/license

The files are used as local page artwork and are not redistributed as an asset pack.

`about-students-reference.png` is project-specific generated artwork created for
the About page's student invitation panel. It is not part of the unDraw set.
`about-students-cutout.png` is the transparent-background derivative used by the
page so the illustration integrates with the section without a rectangular edge.
